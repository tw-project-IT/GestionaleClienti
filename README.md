# GestionaleClienti

Gestionale clienti, con attenzione alle manutenzioni effettuate

### Funzionalità

- login google con whitelist indirizzo email (https://www.npmjs.com/package/@react-oauth/google)
- aggiunta cliente
- aggiunta caldaie
- aggiunta manutenzione caldaia
- Caldaie fatte un anno fa colore giallo, Piu di 2 anni fa rosso

### Pagine

- homepage (Contatore caldaie da fare, Tutte le caldaie da fare, Tuttle le caldaie con note o info)
- lista clienti
- lista caldaie: sortato per manutenzione, se è presente una nota nell'ultima manutenzione c'è un segnale
- pagina lista manutenzioni
